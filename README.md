# downloader

Замер скорости скачивания по URL: делает N последовательных запросов,
читает тело целиком, считает TTFB, время скачивания и скорость по каждому
запросу, в конце печатает сводку.

## Требования

- Node.js ≥ 18 (используется `node:http`, `node:perf_hooks`, ESM)

## Запуск

```bash
npm start <url> [n=10]
# или
node src/index.js <url> [n=10]
```

Пример:

```bash
npm start "https://live.staticflickr.com/7151/6760135001_ddc2c15fd3_6k.jpg"
```

## Что и как меряется

- **wire-байты**: отправляем `accept-encoding: identity`, чтобы сервер
  не сжимал тело — иначе считали бы распакованный объём, а не сетевой.
- **скорость** = `bytes / downloadMs`, где `downloadMs` — от первого до
  последнего байта. `TTFB` (DNS + TCP + TLS + server latency) в неё не входит:
  иначе на маленьких файлах скорость была бы занижена handshake'ом.
- **keep-alive agent** переиспользует сокет между запросами — DNS/TCP/TLS
  платит только первый запрос (отмечен `*` в выводе).

## Единицы измерения скорости

Скорость выводится **автоматически** в одной из трёх единиц — в зависимости
от величины числа, чтобы не показывать «0.00 МБ/с» на медленном канале
и «523487.91 КБ/с» на быстром.

| Диапазон (байт/с) | Единица вывода | Пример |
|---|---|---|
| < 1024             | **Б/с**    | `950 Б/с`     |
| 1 024 – 1 048 575  | **КБ/с**   | `512.0 КБ/с`  |
| ≥ 1 048 576        | **МБ/с**   | `5.48 МБ/с`   |

Пороги — **двоичные** (1 КБ = 1024 Б, 1 МБ = 1048576 Б), как принято
для размеров файлов и объёма памяти.

> **Важно:** `МБ/с` (мегабайт) и `Мбит/с` (мегабит) — разные единицы.
> 1 МБ/с ≈ 8.39 Мбит/с. В сводке пропускная способность дополнительно
> показывается в скобках в `Мбит/с` — чтобы результат можно было сверить
> с тарифом провайдера без ручного пересчёта.

## Флаги окружения

- `NO_COLOR=1` — отключить цвета (см. https://no-color.org).
- При пайпе в файл/`less` live-прогресс-бар и ANSI-последовательности
  автоматически отключаются (проверка `process.stdout.isTTY`).

## Структура

```
src/index.js       — точка входа
src/config.js      — константы
src/colors.js      — ANSI и цветовые хелперы
src/format.js      — форматирование чисел, прогресс-бар
src/stats.js       — mean / median / min / max
src/cli.js         — разбор argv
src/http.js        — keep-alive agent + GET с редиректами
src/measure.js     — одно измерение
src/render.js      — печать шапки, строк и сводки
```
